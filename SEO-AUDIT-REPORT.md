# SEO-аудит: dez-obrabotka.pro

**Дата:** 5 июля 2026
**Бизнес-тип:** Локальная служба дезинсекции (Пенза)
**Страниц в sitemap:** 65
**Стек:** Статический HTML/CSS/JS, без фреймворков

---

## Executive Summary

**SEO Health Score: 72/100**

Сайт технически выполнен на хорошем уровне: семантический HTML, корректные canonical/meta tags, Schema.org LocalBusiness, адаптивный дизайн. Основные проблемы — thin content на страницах услуг, отсутствие отзывов, недостаточная глубина контента и неоптимизированный hero-video для LCP.

### Топ-5 критических проблем
1. **Hero-video ~4.5MB без preload/poster** — критически замедляет LCP
2. **Thin content** на страницах услуг (~400 слов вместо 800-1200)
3. **Нет блока отзывов** — ни на одной странице (критично для YMYL-сферы)
4. **Title главной 95 символов** — обрезается в SERP
5. **Meta description главной 198 символов** — обрезается, нет CTA

### Топ-5 быстрых побед
1. Добавить `preload` + `poster` для hero-video
2. Добавить блок отзывов (5-10 шт.) на главную и услуги
3. Сократить title до ~55 символов, meta desc до 155
4. Добавить `Service` Schema на каждую страницу услуги
5. Исправить грам. ошибку на /contacts/ ("по Пензенская область")

## 5. Performance (10%)

### LCP (Largest Contentful Paint)
- **Проблема:** Hero-video ~4.5MB (H.264) загружается без `preload="none"` и без poster
- Видео автоматически стартует при загрузке страницы
- **Исправление:** Добавить `<link rel="preload" as="video">` + poster изображение

### Render-blocking Resources
- 3 CSS-файла загружаются синхронно (main.css, layout.css, components.css)
- ~300 строк inline CSS в `<head>`
- **Рекомендация:** Объединить в 1 файл или разделить critical/non-critical

### Изображения
- Все иконки — inline SVG ✅ (ноль запросов)
- Hero-video — единственный тяжёлый ресурс
- На страницах услуг нет ни одного `<img>` — весь контент текст + SVG
- Нет lazy loading, srcset, WebP/AVIF

### JavaScript
- Весь JS — inline, без внешних файлов
- City-switcher (~150 строк) делает fetch к 2 API (ipapi.co, ipify.org)
- **Рекомендация:** Вынести city-switcher в отдельный файл с `defer`

### Шрифты
- 3 семейства: Space Grotesk, Inter, JetBrains Mono
- Загрузка через Google Fonts с `display=swap` ✅
- JetBrains Mono используется в 2-3 местах — можно lazy-load

### Сторонние скрипты
- **Нет** GA, Yandex.Metrica
- **Нет** chat-виджетов
- **Нет** рекламных скриптов
- Только geo-fetch (ipapi.co/ipify.org) — минимальная нагрузка
